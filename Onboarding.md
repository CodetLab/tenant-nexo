# Onboarding

## Objetivo del proyecto

Nexo busca resolver la gestión interdisciplinaria dentro de instituciones educativas mediante una plataforma colaborativa.

## Conceptos principales

### Organización

Representa una institución educativa.

### Usuario

Profesional perteneciente a una organización.

### Estudiante

Persona que recibe seguimiento institucional.

### Observación

Registro realizado por un profesional.

### Estrategia

Acción pedagógica reutilizable.

### Reunión

Instancia de análisis interdisciplinario.

## Flujo principal

1. Se crea un estudiante.
2. Los profesionales registran observaciones.
3. Se asocian estrategias.
4. Se realizan reuniones.
5. Se registran acuerdos.
6. Se realiza seguimiento continuo.
